# DiPlay Tesla 0.1.11 — 本地构建候选

本版准备交付本地 APK，**尚未在 GitHub 发布新 Release 或部署网站**。包名保持 `com.diplay.tesla`，版本代码由 11 升为 12。沿用同一发布签名才可覆盖安装并保留数据；`.debug` 源码验证包不是正式版的替代更新。

## 相对已发布 0.1.10

- 整合此前的 DiPlay 0.2.16 → 0.2.21 同步，以及截至 2026-10-27 的后续主线修复：连接恢复、音频时钟、触控、设置备份、韩语、诊断和输入边界硬化。上游版本号仍为 0.2.21，不将主线变更冒称已发布 0.2.22。
- 保留此前 WheelPlay 启发的 50 ms 压缩帧队列、5–60 fps 请求、4/10/30 秒恢复等待及默认关闭的 Canvas 选项；JPEG 仍最多 30 fps。这些是源码行为，不是车机已测性能承诺。
- 选择性适配新 WheelPlay 的 AirPlay 验签控制门禁、失败状态清理和明密切换边界；保留 DiPlay 的缓冲音频、PNG 与现有解析上限，不称已经移植其全部协议硬化。
- JPEG 回退后按 5/10/20/30 秒退避重新尝试 RTC；连续健康显示 60 秒后重置退避。明确不支持的能力错误停止自动尝试，临时播放权限限制仍可恢复。重试协商期间 JPEG 保持可用，不取消 JPEG 长按；真正传输切换仍释放触摸。
- 修复主线同步接缝：远端浏览器视频不再触发 Android 无首帧误告警，Tesla APK 更新筛选与新的下载安全规则共存，补齐韩语浏览器设置文案及音频模拟 fixture。

详见 [本次同步说明](UPSTREAM-SYNC-20261028.md)、[RTC 退避说明](TESLA-RTC-RETRY.md)、[此前视频增强对比](TESLA-WHEELPLAY-COMPARISON.md)及 [第三方归属](THIRD_PARTY_NOTICES.md)。

## 验证与安装边界

组合源码门禁为 3,620 项测试（3,619 通过、1 条无 IPv6 条件跳过）、五项 debug lint、四个普通 debug APK、RTC 三 ABI，以及 74 项 Node 测试通过；精确源码提交和边界见 [本次验证记录](UPSTREAM-SYNC-20261028.md#wheelplay-与-0111-组合验证)。本轮没有新的 Tesla、iPhone 或 V50 真机结果；0.1.10 的历史实车反馈不覆盖本版新增策略。

普通源码验证构建不含 `offline-mfi` 认证资产，不能作为已配置完整连接版的无条件替代。完整连接构建必须在可信本地使用原先已授权的资产；发布签名私钥、密码和认证资产均不得进入 Git、云验证包或公开日志。未取得原签名时，不生成新发布密钥冒充可升级版本。
