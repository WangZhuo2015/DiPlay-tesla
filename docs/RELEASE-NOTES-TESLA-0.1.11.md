# DiPlay Tesla 0.1.11 — 待发布候选

本候选仍在整理验证，**尚未发布新的 GitHub Release 或正式 APK**。发布包名保持 `com.diplay.tesla`，versionCode 为 12；覆盖 0.1.10 并保留数据需要原发布签名。独立 `.debug` 包不是正式覆盖升级包。

## 本次整合

- **独立导航音量：** 网页菜单增加 −20～0 dB 滑块和 ± 按钮，复用 Android 保存值与实时 PCM 增益。只降低导航提示，不改变音乐音量；快速操作合并提交，其他端改值或保存未确认时先回读。
- **实际视频状态：** 菜单直接显示 WebRTC／JPEG、收到的尺寸、实测帧率及回退原因。统计不可用显示“未知”，静止画面可实测为 0 fps；不使用目标分辨率和设置帧率冒充测量结果。
- **性能调整：** 整合 [PR #5](https://github.com/WangZhuo2015/DiPlay-tesla/pull/5) 的单槽 JPEG 编码工作、NV21／压缩缓冲复用、按浏览器需求启停转换、RTC NAL／队列处理、Canvas 回调和音频状态去重。保留有界丢帧策略，没有为条件性静态末帧场景增加额外拷贝。
- **说明文档：** 默认 README 改为中文，以 Tesla 安装、连接、设置和故障排查为主；不再附带旧版通用车机的宣传、发布日志和安装入口。项目名、包名、许可证和必要作者署名保留。

性能调整减少了部分不必要的工作；主机基准不代表实际车机帧率、温度或延迟已经改善。[实现范围和实测计划](browser-performance.md)

## 此前已包含的源码更新

- 同步接收端至 0.2.21 及截至 2026-10-27 的后续修复，涉及连接恢复、音频时钟、触控、设置备份、语言和诊断。
- 保留 50 ms 压缩帧队列、5～60 fps 请求、4／10／30 秒恢复等待和默认关闭的 Canvas 选项；JPEG 最多 30 fps。

- 选择性适配 AirPlay 认证边界和失败状态清理，不宣称移植了参考项目的全部协议行为。

## 验证状态

性能分支 `b4493e635072f07f5cf69a39af07e0cf15635579` 的[精确提交 Android CI](https://github.com/WangZhuo2015/DiPlay-tesla/actions/runs/41044572300)通过。导航音量实现 `9904b44c` 另有本地 Android、浏览器和合成界面验证；其 Mac 上存在三项未改动的双栈网络测试失败，详见[验证记录](testing/tesla/README.md)。这些独立结果不能直接当作本候选的整合验证。

本次整合的轻量浏览器／代理测试为 **92 项全部通过**，JavaScript 语法、公开源码凭据检查和 diff 检查通过。为避免影响同机真实音频连接测试，整合后的 Android 构建、测试与 lint 尚待资源空档执行；没有为此启动大编译、模拟器或 ADB。

目前没有新的 V50、iPhone 或 Tesla 实车结果。静态源在编码繁忙时结束发送属于待验证的条件性场景，不是已确认的实车缺陷，也没有被认定为必须修复才能合并的阻断问题。
