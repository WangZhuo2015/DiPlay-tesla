# DiPlay Tesla 0.1.10 — 默认浏览器音频与收起式菜单（本地测试）

浏览器音频默认开启。配对或点按页面会尝试启动声音，手动关闭会保存在当前浏览器，刷新与重连后仍保持关闭。浏览器自动播放策略要求用户手势时，无需再专门打开菜单启用音频。音乐与导航仍走现有 PCM 通道；通话、Siri 语音和麦克风仍使用 Android 主机。

菜单入口改成顶部中央小把手，闲置两秒后收起，只露出顶边 12 px。点击直接展开，键盘聚焦时显示完整按钮。画面尺寸和触摸坐标保持原样。

移除电池温度字段。没有物理电池的供电设备也可能暴露 Android 电池广播，不能据此宣称真实电池温度。摘要保留从命名热传感器读取的 SoC 温度；详细诊断保留其他热传感器名称和读数。过期数据仍显示“未更新”。

包含 0.1.9 的触摸修复：松开时保留最终坐标，快速按下／松开按顺序发送，只合并中间移动。用户已确认 0.1.9 的 HTTPS 页面能正常切换左侧图标，画面和声音连续。

保留 1/2、3/4、1× 窗口适配缩放、720p／1080p／2K 预设、独立右侧／全屏配置、隐藏的虚拟按键、H.264 WebRTC 和 JPEG 回退。Android 本机 HTTPS 网关独立配置，具体域名、证书和设备配置留在本地，APK 与公开仓库不包含这些部署数据。

完整 Android CI、2271 项 Android 单元测试和 29 项浏览器／代理测试通过。合成网页验证了默认开启、关闭后刷新仍保持关闭、重新开启和 PCM 接收；全屏、紧凑与阿拉伯语 130% 字体截图已检查，均没有真实账号、位置或 CarPlay 内容。签名构建通过，0.1.10 已安装到 V50；真实默认音频和新把手效果待用户确认。

包名 `com.diplay.tesla`，versionCode 11，版本 `0.1.10`，沿用原签名。本地独立连接 APK 包含此前明确配置的实验性 MFi 资产，文件与输入一致；认证资产没有进入源码，普通源码构建仍需自行配置。该本地 APK 尚未公开发布。
