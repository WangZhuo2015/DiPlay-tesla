# DiPlay Tesla 0.1.4 — 简化配对与网页输出（本地测试）

网页连接改为输入 6 位数字，或使用手机连接页复制的链接。打开“连接 → Tesla 浏览器”时生成新码，5 分钟有效；输错 5 次后需重新打开该页。短码通过同源接口换取内部访问凭证，浏览器保存在本机，刷新或再次打开不必重复配对。原来已配对的浏览器和旧链接仍可连接，MFi 认证不受影响。

Tesla 版的视频只交给浏览器，停止向 Android 本地解码器同时发送视频。手机保留连接状态、设置、音频与麦克风处理。WebRTC 成功显示时仍暂停 JPEG 解码，失败时保留 JPEG 回退。普通 DiPlay 的手机画面不受此改动影响。

网页首帧反馈继续通知核心，稳定播放后无线重试计数正常复位。完整 CI 通过，2264 项单元测试零失败。V50 的实际 1920×1080 WebRTC 视频正常，手机不再持有活动视频解码器。音乐 AAC 解码和网页 PCM 缓冲已观察到，用户确认听到声音；所选目标缓冲为 400 ms。该 V50 的 Android AudioTrack 不可用，网页音频关闭时不能假定本地扬声器会接管。

网页菜单从顶部横向展开，关闭后画面使用整个可用区域；虚拟按键继续默认隐藏。全屏和右侧窗口各自保存分辨率，保存时不自动中断会话。

包名 `com.diplay.tesla`，versionCode 5，版本 `0.1.4`，沿用原签名。含此前配置的 MFi 资产的 APK 仅用于本地测试，尚未公开发布。后续音频采样记录到一次重新缓冲；持续音频听感、scrcpy 稳定性和 Tesla 实车效果仍需实际验证。
